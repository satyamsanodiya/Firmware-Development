# Firmware-Development
In this repo, I've saved my Embedded C learning journey and Device driver development....
---

## 📂 Core Platforms

### 🔹 STM32 Nucleo (ARM Cortex-M4)
* **Environment:** STM32CubeIDE / Embedded C
* **Focus:** Peripherals configuration (UART, SPI, I2C, Timers, ADC) using both HAL libraries and direct register-level optimization.
* **Key Implementations:** RS485 and CAN bus industrial communication protocols.

### 🔹 ESP32
* **Environment:** Arduino IDE / ESP-IDF
* **Focus:** Wireless networking, real-time data streaming, and interfacing physical sensors with cloud-based IoT dashboards.
